# Guia visual del sistema

## Tablero

Pantalla principal para revisar el estado general:

- Ofertas activas.
- Clientes registrados.
- Vehiculos vendidos.
- Ingresos totales.
- Utilidad estimada.
- Catalogo de ofertas activas con filtros.

## Clientes

Flujo para personas que pueden vender o comprar vehiculos:

- Registrar nombre completo, domicilio, correo y telefono.
- Buscar clientes por texto.
- Editar clientes existentes.
- Eliminar clientes cuando no tengan restricciones de base de datos.

## Vehiculos

Flujo de publicacion:

- Seleccionar vendedor.
- Capturar numero de motor, numero de serie, modelo, marca, linea, color, precios, transmision, cilindros, nacionalidad, descripcion, observaciones e imagen.
- Ver el inventario completo.
- Abrir detalle completo.
- Editar o eliminar solo vehiculos publicados.
- Los vehiculos vendidos quedan protegidos.

## Ventas

Flujo de compraventa:

- Seleccionar un vehiculo publicado.
- Seleccionar comprador.
- Capturar precio final, estatus de pago y lugar.
- Confirmar venta.
- El sistema cambia el vehiculo a vendido.
- Se genera acta HTML formal para imprimir.

## Reportes

Incluye los reportes solicitados:

- Ofertas activas ordenadas por fecha de publicacion.
- Vehiculos vendidos con fecha de venta.
- Exportacion CSV.
- Impresion desde navegador.
- Regeneracion de acta.
- Cancelacion de venta para republicar vehiculo.
